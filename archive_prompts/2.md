# Objective

Complete the production-grade backend foundation. By the end of this
stage the repository should contain a stable infrastructure that later
prompts can extend with LangChain, LangGraph, streaming, analytics and
the frontend.

------------------------------------------------------------------------

# Required Backend Architecture

Implement a clean layered architecture.

``` text
API Layer
    ↓
Service Layer
    ↓
Repository Layer
    ↓
Database Layer
```

Business logic must never exist inside routers.

Routers should: - Validate requests - Call services - Return responses

Repositories should: - Perform only persistence - Never contain business
rules

Services should: - Coordinate workflows - Handle transactions - Raise
domain-specific exceptions

------------------------------------------------------------------------
